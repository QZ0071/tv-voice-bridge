# 验证记录

## 原设备技术基线

日期：2026-10-28。设备：哈趣 K1 Pro，Android 9，`marconi / HQK1Pro`。

- 使用原生 Rocky / 思必驰 DDS 识别结果。
- 用户用真实遥控器在影视仓输入框说“喜羊羊与灰太狼”，确认正确填入且页面不退出。
- 用户在桌面说“我想看熊出没”，确认打开影视仓并搜索剥离前缀后的影片名。
- 恢复原生助手界面；输入框会话仍不触发影片跳转。
- ADB 保持启用；未替换用户桌面或默认输入法。

这些是个人适配版 2.1 的实测结论，不能自动等同于公开 APK 已在所有同型号固件上完成验证。

## 公开框架

- Python 部署测试：设备匹配拒绝、只读检查、帧解析、保留其他无障碍服务、部署成功、失败回滚、已有插件拒绝覆盖和跨设备备份拒绝。
- Android 单元测试：原生语义 title 优先、无效 JSON 回退与长度限制、听写会话防止重复影片搜索。
- `assembleRelease` 与 Android lint vital 检查。
- 发布前运行精确设备的 `--check`；不通过就不会对该设备宣称适配。

公开安装器的真实部署、默认入口自动设置和其他厂商的远程麦克风，需另行记录验证结果。请在 issue 中明确区分模拟测试、接口检测、真实按键测试；不要只写“支持所有 Android TV”。
